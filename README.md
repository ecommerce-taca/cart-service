# Cart Service 

Starter project for `ecommerce-microservices` based on the Cart LLD / DB / API / Test documents (2026-11-01).

## Stack

- Java 25
- Spring Boot 4.1.2 (stable release checked 2026-11-01)
- Maven
- Spring MVC + Validation
- Spring Data MongoDB (MongoDB 8.x is targeted in the next steps)
- Actuator
- JUnit 5, MockMvc-related test starter and Testcontainers dependencies

## Requirements

- JDK 25 (`java -version` and `mvn -version` must point to JDK 25)
- Maven 3.9.x recommended
- Docker Desktop for MongoDB in the later Phase 1C and Testcontainers integration tests
